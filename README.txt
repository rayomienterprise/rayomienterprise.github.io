# JMP IT Consulting - sitio web HTML5

## Estructura
- index.html: estructura semántica HTML5.
- styles.css: diseño responsive, animaciones, tarjetas, navegación y efectos.
- script.js: carruseles, menú móvil, scroll, animaciones y botón volver arriba.

## Cómo ejecutar
Abrir `index.html` directamente en Chrome/Edge/Firefox.

## Imágenes
La demo utiliza imágenes remotas de Unsplash para facilitar la visualización inmediata. Para producción se recomienda descargar/gestionar imágenes con licencia adecuada y alojarlas localmente o en un CDN.

## Personalización
Cambiar en `index.html`:
- Nombre de empresa.
- Correo.
- Teléfono.
- Redes sociales.
- Textos de servicios.
- Imágenes.
- Enlaces de contacto.

## Nota de diseño
La estructura toma como referencia patrones habituales de sitios corporativos tecnológicos modernos: hero visual, navegación fija, bloques de servicios, carruseles, métricas y CTA. No replica código, textos ni elementos propietarios del sitio de referencia.
